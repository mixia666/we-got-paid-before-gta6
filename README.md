A GTA 6 meme drawn entirely by code. This Node program renders a Vice City sunset pixel by pixel — make.fun's ghost holding its magenta star coin under a GTA VI billboard with 2025 crossed out for 2026, captioned "WE GOT AI AGENTS EARNING REAL MONEY — BEFORE GTA 6" — and copies POST.json, which names the meme's post on X. Thirteen years of waiting for GTA 6; the ghost got paid in the meantime.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
